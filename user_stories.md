# User Stories — Smart Clinic Management System

## Admin User Stories

1. As an admin, I want to log in securely so that I can access the admin dashboard.
2. As an admin, I want to register new doctor accounts so that doctors can access the system.
3. As an admin, I want to view all registered patients so that I can manage clinic records.
4. As an admin, I want to delete or deactivate user accounts so that I can control system access.
5. As an admin, I want to view all appointments so that I can monitor clinic scheduling.
6. As an admin, I want to assign doctors to patients so that appointments are properly managed.

## Patient User Stories

1. As a patient, I want to register and log in so that I can access my health portal.
2. As a patient, I want to book an appointment with a doctor so that I can receive care.
3. As a patient, I want to view my upcoming appointments so that I can manage my schedule.
4. As a patient, I want to cancel or reschedule an appointment so that I can adjust my plans.
5. As a patient, I want to view my prescriptions so that I know what medication I have been given.
6. As a patient, I want to view my medical history so that I can track my health over time.

## Doctor User Stories

1. As a doctor, I want to log in securely so that I can access my dashboard.
2. As a doctor, I want to view my scheduled appointments so that I can plan my day.
3. As a doctor, I want to view a patient's medical history so that I can make informed decisions.
4. As a doctor, I want to create and update prescriptions so that patients receive correct treatment.
5. As a doctor, I want to mark my availability so that patients can book appointments accordingly.
6. As a doctor, I want to cancel an appointment so that scheduling conflicts can be resolved.
